01 — What changed

Advanced search

In the last round, testers did not find Advanced search. An Advanced filter switch now replaces the Quick and Advanced tabs.

  • +Inside the search fieldThe switch sits in the search field on the start screen and in the composer on the results page.
  • +One control, two modesOne on/off switch replaces two tabs. The field stays in place, and only the area under it changes.
  • +Miller columns under the fieldWith the switch on, the Miller columns show three at a time, with the filter box below them.

01 — What changed

Loading states

In the last round, testers could not tell whether a search had run. The prototype now shows each state of a search.

  • +A loading state on the tableThe table shows a loader after every search and after every filter change.
  • +The Miller columns walk to the queryWhen a typed query resolves, the columns move through each attribute in turn.
  • +The table does not waitThe filters apply before the walk starts, so the table never waits for it.
  • +An empty state with recoveryWhen a search finds nothing, the table names the filter to remove and offers two actions.

01 — What changed

Results layout

The results page is now one grid. A chat panel sits beside the table, under the filter row.

  • +A chat panel beside the tableThe commonly used filters head the panel. The query field sits at its foot, as a chat composer does.
  • +A collapsible panelA toggle in the footer folds the panel away to the side, and opens it again.
  • +One status barThe count, Columns and Export run across both the panel and the table.
Screenshot

01 — What changed

Tick boxes

In the last round, a tapped value was added instead of replacing the value before it, and a value could not be removed once added. Each value now shows a tick box.

  • +Select one, or addClicking the row selects only that value. Clicking the box adds it to the values already selected.
  • +Remove by untickingUnticking a value removes it. The × on a filter removes the whole filter.
  • +Clear at restAn unticked box shows its edge, and a part-selection shows a bar.
  • +One control throughoutThe same tick boxes show in Add filter and in the column menus.
Screenshot

01 — What changed

Column filters

Filters set from a column follow the rule agreed on 30 September: every filter that reduces the results shows in one place, the filter row at the top.

  • +A count per columnEach column head shows the number of values applied to it.
  • +Edit, add or clearThe column menu holds Edit filters, Add filter and Clear filters.
  • +One shared stateA change made from a column writes back to the filter row at the top.
  • +Idea 1c onlyThe control has no column filters. Task 6 shows whether testers start at the columns or at the filter row.
Screenshot

01 — What changed

Filter experience

Two changes make the filter row easier to extend and easier to read.

  • +A labelled Add filterThe button reads “+ Add filter”, not a bare + icon.
  • +The full field listAdd filter opens every field, not four, with a breadcrumb and a search field.
  • +Three lines at mostThe filter row stops at three lines, so it does not crowd out the results.
  • +The rest in a popoverThe remaining filters fold into a count. The count opens a popover that holds them.

02 — User testing plan

Questions

Seven tasks, then NPS. Tasks 1 to 3 repeat the last round word for word. Task 4 no longer names the builder. Tasks 5 to 7 are new.

Task 1 G1
Find all Phase III drugs in Europe that act on Janus Kinase.
Task 2 G2
Change the last search. Replace Europe with the United States.
Task 3 G3
Use plain language to find a set of five filters.
Task 4 G3
Find the same drugs again. Choose each filter by hand.
Task 5 G2
Remove the route of administration from the search.
Task 6 G2
Show only the drugs from one company in the list.
Task 7
Find Phase I gene therapies for dermatology in Brazil. If there are no results, change the search.
NPS
How likely is the tester to recommend this way of searching to a colleague?

02 — User testing plan

Measures

Each measure compares Idea 1c with the control.

1–5
Ease per task
1 is Very difficult and 5 is Very easy. Scored after each of the seven tasks.
0–10
NPS
0 is Not at all likely and 10 is Extremely likely. The standard NPS scale.
Why
Written response
One sentence after every score that explains the reason for it.
