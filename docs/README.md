# Docs

One folder per sprint. Mirrors `slides/` and `sprints/`.

```
docs/<sprint>/decks       deck outlines and source notes
docs/<sprint>/scratchpad  loose working notes, not deliverables
docs/<sprint>/research    inputs — client material, references, benchmarks
docs/<sprint>/exports     PDFs and screen exports handed to the client
```

- `slides/<sprint>/` holds the built HTML decks.
- `sprints/<sprint>/` holds the brief, the flow reading, and the decision log.

Markdown filenames are all caps with hyphens; HTML filenames are sentence case.
