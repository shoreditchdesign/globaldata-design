# Sprint 4 user testing — questions

Scale wording, used throughout: **1 = very easy, 10 = very difficult.**

---

**1.** Find every Phase III drug available in Europe that works on Janus Kinase.
- How difficult was achieving this? `1–10`
- What was the main reason for your answer?

**2.** Using the search you just built, swap Europe for the United States.
- How difficult was achieving this? `1–10`
- What was the main reason for your answer?

**3.** Write a search in your own words, run it, and read the results.
- How difficult was achieving this? `1–10`
- What was the main reason for your answer?

**4.** Find that same set again through the advanced search, using the file explorer to locate each filter by hand.
- How difficult was achieving this? `1–10`
- What was the main reason for your answer?

---

**5.** How likely are you to recommend this way of searching to a colleague? `0–10`
- What is the main reason for your score?

---

**Notes for setting it up in Lysnna**

- Two identical tests, one per prototype link, so the scores can be compared directly.
- Tasks 1 and 2 are the first two goals: the quick screen at three filters, then the refine.
- Task 3 is the natural-language route, and how close what came back is to what was asked for.
- Task 4 follows it straight away, so the same intent is built twice and the typed route can be compared with the advanced search within one tester — Miller columns in one option, the file tree in the other.
- Ask for the score straight after each task, before the tester sees the next one.
- Check that Janus Kinase and the two regions resolve in both prototypes before sending it out, so the scores measure the design rather than the sample data.
